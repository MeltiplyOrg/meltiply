# Cloudflare API Shield

Use API Shield for API discovery, protection, and monitoring — schema validation, JWT validation, mTLS, BOLA detection, and authentication posture. API Shield is an Enterprise add-on; check [plan availability](https://developers.cloudflare.com/api-shield/index.md) before promising features.

## Choose a task

| Task                                                               | Start here                        |
| ------------------------------------------------------------------ | --------------------------------- |
| Set up Schema Validation 2.0, JWT validation, or mTLS              | [Configuration](configuration.md) |
| Manage endpoints or use discovery and validation APIs              | [API](api.md)                     |
| Detect BOLA attacks, track auth posture, or roll out progressively | [Patterns](patterns.md)           |
| Diagnose validation failures or false positives                    | [Gotchas](gotchas.md)             |

Classic Schema Validation is deprecated — configure Schema Validation 2.0 for new setups.
