Meltiply does not provide a dedicated `/analytics` screen or sidebar Analytics navigation item. Visiting `/analytics` redirects to the posts hub on the [Publishing](/docs/publishing) screen.

All mock preview panels — including illustrative Link Clicks, Net Growth cards, and AI Insights — have been removed from the application.

## Current availability

The Posts **Table** shows **Likes**, **Cmts** (Comments), **Shrs** (Shares),
**Saves**, **Clicks**, **Views**, **Impr.** (Impressions), and **Reach**. Use the
**Columns** menu to hide or restore individual counters. Wide tables scroll
horizontally on desktop and phone.

Only published Channels contribute measurements. Each Post sums the latest
stored snapshot for each measured published Channel; it never adds historical
snapshots together. Channels without snapshots contribute no invented values.
Drafts, unpublished Posts, missing snapshots, and unsupported/untracked counters
show `-`. A measured zero remains `0`. **Saves** and **Clicks** are currently
untracked, so those columns show `-`.

These are the latest stored provider measurements, not guaranteed live counters.
They refresh with Post data after the backend synchronizes. Reach is summed per
Channel, not deduplicated across audiences or platforms. For metrics the
connected provider does not supply, use its native reporting tools.

## Backend analytics capabilities

Backend provider synchronization services and the API endpoints `/api/v1/analytics` and `/api/v1/analytics/{distribution_id}` retain aggregate and per-distribution platform metrics for supported channels.

An interactive front-of-house analytics reporting dashboard and aggregate charts are not exposed in the web interface.
