The **Channels** page uses a Members-style directory: a centered heading and actions, underlined **Accounts** / **Brand Profiles** tabs, search and connection-status segments, and a bordered account table with identity rows and labeled health badges. It shares Posts' background, typography, controls, and card tokens. The Brand Profiles tab shows real profile cards and connected-account counts.

## Before you connect

Connecting a channel requires a **Brand Profile** — every connection belongs to exactly one profile. If your workspace has no profiles yet, the **Add account** button stays disabled:

- **Admins** see a prompt to create a Brand Profile first (use **Create Brand Profile** in the header — see [Workspaces & Brand Profiles](/docs/workspaces)).
- **Members** see a prompt to ask a workspace admin.

## Connect an account

1. Select **Add account** in the Channels header.
2. Choose the **Brand Profile** that will own the connection.
3. Find your platform — scroll inside the Social Channels list or use the search field to filter it.
4. Select **Connect**. You're redirected to the platform to sign in and approve Meltiply's access.
5. After approving, you're returned to the Channels page. For **Facebook**, choose a Page in **Select Facebook Page**, then select **Connect Page**; nothing is connected automatically, even when only one Page is eligible. Other platforms return their connection result directly. An account appears only after it is saved successfully.

To connect a second account on the same platform under the same profile — for example, two TikTok accounts for one brand — select **Add Another** on that platform's row.

Facebook lists Pages for which you have content-creation access and have granted the required publishing permissions. The chooser expires after ten minutes. **Cancel**, the close button, or Escape discards an unconfirmed selection without adding an account.

If the chooser reports a connection limit, disconnect an existing account or upgrade the verified plan, then retry the same chosen Page while the selection is valid. Expired selections require starting **Connect** again.

Already-linked accounts appear by their saved account name, or provider account ID
when no name is available. A green tick marks a healthy connection; accounts that
need attention show their connection status instead. If new connections are
unavailable, these identities replace the disabled **Unavailable** button.

You can also open the connect dialog directly at `/channels?tab=add`.

### Available platforms

You can connect accounts on:

- **TikTok** — short-form videos with custom sound and caption settings
- **YouTube** — long-form videos and Shorts
- **Instagram** — feed posts, Reels, and carousels
- **Facebook** — Pages with content-creation access
- **Threads** — text threads, single photos, and link posts

### If connecting fails

If you cancel the platform's permission prompt or the authorization can't be completed, no account is added — start the connection again from **Add account**. If it keeps failing, see [Troubleshooting](/docs/troubleshooting).

Facebook requires you to choose one eligible Page, rather than authorizing exactly
one Page. When Facebook omits the user token's lifetime from its exchange
response, Meltiply inspects the token to obtain its actual expiry. A valid token
with an inspected expiry of zero has no time-based expiry; Meltiply stores no
expiry date rather than treating it as 1970 or assuming a new 60-day lifetime.
Such tokens can still lose access through revocation or Facebook's data-access
rules. Invalid, expired, or unverifiable tokens are rejected.

Unrecognized connection-result codes are ignored rather than shown as success or
interrupting the Channels page.

## Read the directory

The **Accounts** tab presents a searchable, filterable table. Its rows contain:

- **Account identity** — avatar or initials, display name, and available username/provider ID with separate copy buttons.
- **Platform** — the provider mark and name.
- **Brand Profile** — the owning profile, or **Unknown profile** if the owner no longer resolves.
- **Connection** — healthy indicator or the actual connection status and recovery control.
- **Actions** — the channel settings overflow action opens its current profile, permissions, publishing support, and confirmed disconnect controls.

Select **Brand Profiles** to review the actual profiles as cards. Their counts include real connected accounts in the workspace, not just the current account filters. Admins can edit profiles; **View channels** applies that profile to the Accounts tab.

The directory toolbar includes account search, visible **Connection status** segments, a **Filter** disclosure for Platform and Brand Profile, and the current match count. Search matches platform name, account name, and profile name. Active filters have removable chips; **Clear all** resets them. If filters hide every account, **Clear filters** restores the listing.

Select channel checkboxes, or the table-header checkbox for all visible filtered
channels. The bottom selection pill shows the total, **Deselect**, and **Disconnect**.
Confirm the selected batch before disconnecting; successful channels leave the
selection and failures remain selected for retry. Selection survives search/filter
changes, but changing the Workspace or Brand Profile clears it.

### Connection statuses

| Status             | Meaning                                                      |
| ------------------ | ------------------------------------------------------------ |
| Connected          | Working normally; shown with a green tick                    |
| Expiring           | Authorization will expire soon — reconnect before it does    |
| Expired            | Authorization lapsed — re-authenticate to restore publishing |
| Reconnect required | Authorize the connection again before it can publish         |
| Revoked            | Access was withdrawn — reconnect to use it again             |

Every non-connected status uses a warning indicator; its accessible control exposes the specific status and reason.

### Filter the account directory

Use the search field, status segments, and **Filter** disclosure:

- **Search** matches platform name, account name, and Brand Profile name.
- **Connection status** segments select all statuses or one actual health state.
- **Platform** in Filter shows selected platforms.
- **Brand Profile** in Filter scopes accounts to one profile or **All Brand Profiles**.

Remove an active filter with its chip or choose **Clear all**. When filters hide every account, **Clear filters** restores the full list.

## Reconnect a channel

When a connection shows **Expiring**, **Expired**, **Reconnect required**, or **Revoked**:

1. In the channel row, select the warning icon, then **Re-authenticate**.
2. You're redirected to the platform to approve access again.
3. For Facebook, select the same Page to renew that channel, then select **Connect Page**. The row returns to **Connected** after the renewed connection is saved.

Re-authentication keeps the channel's existing Brand Profile — nothing needs to be reconfigured.

## Disconnect a channel

Disconnecting removes Meltiply's link to the account.

1. In the channel row, select **Channel settings** (the overflow action), then **Disconnect**. Settings are available in **All Brand Profiles** as well as filtered views.
2. Confirm in the **Disconnect** dialog.

The confirmation warns that **scheduled and queued posts for that channel stop publishing**. Nothing is deleted — you can reconnect the account at any time through **Add account**. To remove it from the platform's side too, revoke Meltiply's access in that platform's own app settings.

## Manage Brand Profiles from Channels

Admins can manage profiles directly from Channels:

- **Create Brand Profile** in the header — after saving, the connect dialog opens so you can link a channel immediately
- **Edit profile** — select the pencil icon inside the Brand Profile filter
- **Delete profile** — inside the profile editor; deleting permanently removes the profile's channels, assets, and posts (see [Workspaces & Brand Profiles](/docs/workspaces))
