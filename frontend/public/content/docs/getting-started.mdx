Each Meltiply installation has one owner. Workspaces and Brand Profiles organize that owner's publishing data; they are not separate sign-up or workspace-switching flows.

## Create the installation owner

1. Open `/sign-in` on an empty installation.
2. Enter the deployment administrator's private **Setup secret**, **Your name**, **Email address**, and a unique **Password** of 8–128 characters.
3. Select **Create owner account**.
4. Follow the email verification link, then return to sign in.

After setup, registration closes. The setup secret is not your login password. Use **Resend verification** if the verification email is missing.

## Sign in and recover access

Enter your email and password on `/sign-in`, then select **Sign in**. If an authenticator is enabled, supply its current code or an unused backup code. Successful sign-in opens **Posts**.

**Forgot password?** requests an expiring reset link; it does not bypass an enabled authenticator. Manage passwords, authenticator enrollment, and recovery codes in [Settings → Security](/docs/settings#security). Sensitive actions require current-password verification.

Sign out from **Account menu → Sign out** at the bottom of the sidebar or **Settings → Account**. Signing out ends the session; it does not cancel already scheduled publishing.

## Prepare your first Post

1. **Create a Brand Profile.** In Channels, workspace admins select **Create Brand Profile**, enter its details, and save. The connection dialog opens for the new profile. Members should ask an admin when no profile exists.
2. **Connect an account.** Use **Channels → Add account**, select the owning profile, and complete platform authorization. Facebook additionally requires explicit Page selection. See [Channels](/docs/channels).
3. **Compose.** Use **Posts → Create post**. Select one owning profile, enter shared content, and add optional [media](/docs/media). Select destination channels when you are ready to publish or schedule; a draft does not require a destination.
4. **Save, schedule, or publish.** Save a draft to return later, choose a publication time, or use Publish Now. Accepted delivery is reported separately for each channel. See [Publishing](/docs/publishing).

## Learn the workspace

| Control                            | What it does                                                                                |
| ---------------------------------- | ------------------------------------------------------------------------------------------- |
| Posts                              | Opens one collection with **Table → Calendar → Grid** in its toolbar. Table is the default. |
| Channels                           | Opens the Accounts directory and Brand Profiles tab.                                        |
| Settings                           | Opens Appearance, Language, Account, and Security.                                          |
| Top-bar search / Command-Control-K | Jumps to a supported destination or loaded Brand Profile.                                   |
| Collection search and Filter       | Narrows the current Posts or Channels data.                                                 |
| Post row/card/chip                 | Opens its publishing details in the side drawer.                                            |

The desktop rail can collapse to icons. Its workspace name is a read-only identity label. Brand Profiles are collection scope, not sidebar sections. Select **All Brand Profiles** to return to aggregate review.

Jump search is not a global Post index. Search captions or accounts in their collection toolbar. The Filter builder adds supported fields; active chips remove individual values and Clear all resets its rows.

## Selection and inspection

Select individual Posts or accounts with their checkboxes. Select-all is checked only when every visible item is selected; the floating pill shows the real count for partial selections too. Confirm destructive batches before proceeding; failed items remain selected for retry.

Post details use a right-side drawer with real properties, caption, attachments, and Channel outcomes. **Expand panel** provides more space; **Restore side panel** returns to the edge. Close returns focus to the opening control. Editing and destructive actions remain in the supported Post workflow.

## Preferences and phones

Appearance offers **Light**, **Dark**, and **System**; System follows device palette changes. Language supports English and Spanish. Current-page changes work immediately; persistence requires [functional cookie consent](/docs/cookies). Security controls appear directly in their Settings section. There is no separate motion mode.

On smaller screens, open navigation from the persistent header. The full-height panel includes Posts, Channels, Help and resources, Settings, and the same Account menu used on desktop, including theme choices and Sign out. Collection controls wrap, wide tables/calendars scroll within their working area, Settings sections become a horizontal row, and Post inspection fills the viewport. Focused dialogs scroll within the available screen height, including landscape orientation.
