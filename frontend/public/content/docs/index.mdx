Meltiply organizes social publishing around **Posts**, **Channels**, named weekly **Queues**, and their owning **Brand Profiles**. Compose text and attachments, save drafts, choose publication times or let a Queue assign a free future slot, and inspect each Channel's actual delivery outcome.

## Start here

1. [Getting started](/docs/getting-started) — create the installation owner, sign in, and learn the workspace.
2. [Workspaces & Brand Profiles](/docs/workspaces) — understand ownership and profile scope.
3. [Channels](/docs/channels) — connect accounts and recover authorizations.
4. [Publishing](/docs/publishing) — compose, schedule, and inspect Posts.
5. [Media](/docs/media) — upload and customize ordered attachments in the composer.

## Find the right surface

| Surface  | Use it for                                                                                                           |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| Posts    | Table, Calendar, and Grid views of real Posts; composition, scheduling, selection, and delivery inspection.          |
| Channels | The Accounts directory, connection health/recovery, and Brand Profile cards.                                         |
| Queues   | Named weekly plans per Brand Profile; timezone/slot configuration, assigned times, membership, and Channel outcomes. |
| Settings | Appearance, Language, read-only Account details, and inline Security controls.                                       |

Posts, Channels, and Queues each have one sidebar entry. Choose **Table → Calendar → Grid** in the Posts toolbar; Table is the default. Brand Profile selection lives in collection filters, the Queues scope selector, or the top-bar jump palette, not another sidebar section.

Use top-bar search or Command/Control-K to jump to a supported page or loaded profile. Search and filter the actual collections from their own toolbars. On smaller screens, the header's navigation menu replaces the desktop rail.

Open a Post to inspect it in the side drawer. Expand it for more space or close it to return to the collection. Selected items use a bottom action pill; destructive actions still require confirmation.

## Capability status

The current interface does not offer an in-app [Inbox](/docs/inbox), [Analytics dashboard](/docs/analytics), or [AI assistant](/docs/agent). Those guides explain what is and is not available; their presence in documentation does not imply an app route.
