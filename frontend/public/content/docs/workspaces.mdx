A **Workspace** is the organization boundary resolved by your sign-in. A **Brand Profile** is a named, color-labeled scope inside that workspace. Every Channel connection, Post, and uploaded asset belongs to one profile.

## Workspace identity

The workspace name appears at the top of the sidebar as a read-only label. The current app has no workspace switcher or plan-tier selector. Review identity in **Settings → Account**, and sign out there or from **Account menu → Sign out** at the bottom of the sidebar.

Use Brand Profiles for independently managed clients, brands, product lines, or regions. Selecting a profile changes collection scope; it does not switch organizations or accounts.

## Select a Brand Profile

On Posts or Channels, open **Filter**, add **Brand Profile** if its row is not present, and choose the profile. Top-bar jump search can also find a loaded profile.

- **All Brand Profiles** is aggregate review.
- A selected profile scopes both Posts and Channels and remains selected when moving between them.
- The composer requires one owning profile; it does not publish on behalf of every profile in the aggregate view.
- Individual/bulk Post deletion and account disconnect use each item's actual owner, so those actions can work in aggregate review too.

Profiles are not sidebar sections. On Channels, the **Brand Profiles** tab shows real cards and connection counts; **View channels** applies that profile and returns to Accounts. A record whose owner no longer resolves remains visible as **Unknown profile** rather than silently disappearing.

## Create a profile

Workspace admins can create, edit, and delete profiles. Members can view/select them but should ask an admin to make ownership changes.

1. Open Channels and select **Create Brand Profile** in the header. The Brand Profiles tab is also where existing profile cards are reviewed.
2. Enter a required **Profile name** (up to 100 characters), optional **Description** (up to 280 characters), and choose a color swatch.
3. Select **Create profile**.
4. After saving, the new profile is selected and account connection opens for it.

Creating a profile does not itself connect a platform account. Complete authorization and any required Facebook Page selection separately.

## Edit a profile

Use a profile card's edit action in Channels, or the edit control in its Brand Profile filter. Update the name, description, or color and save. Editing metadata does not replace its Channels or Posts.

The filter's edit action opens the same profile editor; it is not a second settings implementation. Members see selection without admin editing controls.

## Delete a profile

Open the profile editor, select **Delete profile**, and review the destructive confirmation. The current UI offers irreversible deletion, not a recycle bin or restore workflow. Its associated Channels, assets, and Posts are removed according to the confirmation, and pending publishing stops.

Deleting a stored Post or disconnecting a Channel does not remove copies already published on social platforms. Remove those copies on their platform. Backend retention operations do not imply a self-service restore control in this interface.

## Roles at a glance

| Action                           | Admin | Member |
| -------------------------------- | ----- | ------ |
| View/select a Brand Profile      | Yes   | Yes    |
| Create/edit/delete profiles      | Yes   | No     |
| Connect/re-authenticate accounts | Yes   | Yes    |
| Attach media in the composer     | Yes   | Yes    |

Actions remain subject to the current session, ownership, provider readiness, and resource limits.
