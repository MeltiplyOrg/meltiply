Meltiply organizes everything you do into two levels: a **workspace** at the top, and **Brand Profiles** inside it. Understanding this structure makes every other screen easier to use.

## Workspaces

Your workspace is the organization your account belongs to — typically your company, agency, or personal business. Its name appears at the top of the sidebar as a read-only identity label.

The app does not offer workspace switching or a plan-tier selector. Your active sign-in determines the organization boundary. Inspect account details and sign out from **Settings → Account**, or use the sidebar footer.

Real Brand Profiles appear in the sidebar. Selecting one scopes Posts and Channels within the same workspace; **All Brand Profiles** returns to aggregate review.

## Brand Profiles

A **Brand Profile** is a named, color-labeled scope inside your workspace. Every channel connection, media asset, and post belongs to exactly one Brand Profile.

Use Brand Profiles to separate things you manage independently — for example, one profile per client, brand, product line, or region. Because ownership is per-profile, you can filter every board to just the work for one brand and avoid cross-posting to the wrong audience.

Each profile has:

- **Profile name** (required, up to 100 characters)
- **Description** (optional, up to 280 characters — shown as a tooltip and in empty states)
- **Color** — a swatch that identifies the profile's channels, posts, and assets across the app

### Who can manage profiles

- **Workspace admins** can create, edit, and delete Brand Profiles.
- **Members** can view, select, and filter by the active profile using the Brand Profile dropdown on Channels or Posts, but cannot create, edit, or delete profiles. If you need a new profile, ask an admin — the Channels board indicates when an admin is needed.

### Create a Brand Profile

Workspace admins create Brand Profiles directly on the Channels board:

1. Select **Create Brand Profile** in the top action bar on **Channels**.
2. Enter a **Profile name** (required), an optional **Description**, and choose a color swatch from the honeycomb color palette.
3. Select **Create profile** to save.

Upon saving, Meltiply automatically selects the new profile and opens the account connection dialog so you can link a channel right away.

### Edit a profile

Admins can edit any Brand Profile from the toolbar:

1. Open the **Brand Profile** filter dropdown on the **Channels** board or **Posts** toolbar.
2. Select the pencil icon next to the profile name.
3. Update the name, description, or color in the dialog, then save.

Editing updates profile metadata immediately and does not alter connected channels or existing posts.

### Delete a profile

Deleting a Brand Profile permanently removes the profile and its associated channels, media assets, and posts:

1. Open the profile editor dialog via the pencil icon in the Brand Profile filter on Channels or Posts.
2. Select **Delete** and confirm the irreversible action.

Deleting stops scheduled and queued posts on that profile's channels.

### Soft-deleted profiles

The backend retains soft-deleted Brand Profiles for 7 days before permanent purge. Backend restore operations can restore profile records, but disconnected channels require re-authorization on the Channels board. Explicit deletion confirms permanent removal.

## The active Brand Profile selection

Choose a Brand Profile in the sidebar or the toolbar on **Channels** and **Posts** to control which profile's work you see:

- **All Brand Profiles** — the default aggregate view showing everything
- A specific profile — the board filters to that profile's items, and several actions become profile-scoped

The selection matters because some actions only work with a profile chosen:

- **Uploading media** requires an active profile in the composer.
- **Creating or editing posts, scheduling, and channel-outcome changes** require an active profile.

Channel disconnect and Post deletion, individually or in selected batches, use
each item's owning Brand Profile and also work in **All Brand Profiles**. Deleting
a Post stops its pending channels but leaves already-published platform copies intact.

The selection is shared across screens — picking a profile on Channels keeps it active on Posts. Choose **All Brand Profiles** to return to the aggregate view.
If a channel or post still refers to a profile that no longer resolves in your workspace — for example one awaiting purge — it appears under **Unknown profile** so the item never disappears silently.

## Roles at a glance

| Action                          | Admin | Member |
| ------------------------------- | ----- | ------ |
| Select a Brand Profile filter   | Yes   | Yes    |
| Create / edit / delete profiles | Yes   | No     |
| Connect and reconnect channels  | Yes   | Yes    |
| Attach and upload media         | Yes   | Yes    |
